# Шаблон собранного voice-скила

«Скелет» персонального voice-скила (он и есть генератор текста). При генерации:
1. Заменить ВСЕ `{{...}}` данными из интервью + отчёта `analyze_corpus.py`.
2. Удалить блоки без данных (лишние каналы/тональности).
3. Вместо `{{ANTI_SLOP}}` вставить секцию из `references/universal-anti-slop.md`.
4. Сохранить как `~/.claude/skills/voice-{{slug}}/SKILL.md`.

Порядок секций важен: **примеры идут раньше правил** (модель калибруется по
эталонам сильнее, чем по инструкциям).

## Алгоритм
1. Уточни: канал? тональность? тема?
2. Построй текст, равняясь на эталоны выше.
3. Проверь по чеклисту.

### Чеклист перед выдачей
- [ ] Звучит как {{Имя}}, а не как нейтральный AI.
- [ ] Есть фирменные вводные/обороты, ритм совпадает.
- [ ] Нет забаненных AI-фраз (анти-слой выше).
- [ ] Имя/должность автора не вынесены в текст.
