# Гайд по извлечению Voice DNA

Как превратить интервью + сырые образцы в заполненный `voice-skill-template.md`.

---

## Часть 1. Интервью (что спрашивать)

Порциями, не всё сразу. Сначала блок А, потом Б.

### Блок А — личность и охват
1. **Имя/ник** автора (как подписывать стиль). Отсюда `slug` (латиница, kebab-case).
2. **Кто ты**: род занятий, роль, бэкграунд (1–2 фразы).
3. **Темы**, на которые пишешь чаще всего.
4. **Каналы**: где публикуешь (чат / личный канал / LinkedIn / X / e-mail / блог).
   Для каждого — примерная длина и цель.

### Блок Б — тон
5. **Стиль одной фразой**: прямой? тёплый? саркастичный? академичный?
6. **Тональности**: нужны ли переключатели (нейтрально / мягче / жёстче / ироничнее)?
7. **Личные анти-правила**: чего ты НИКОГДА не делаешь (эмодзи, хэштеги, мат, капс).
8. **Любимые словечки** (необязательно — корпус покажет).

### Блок В — образцы (критично)
5–20+ реальных образцов в этом голосе. Чем больше и «живее» — тем точнее.
Приём: вставка в чат (через `---`); файл (.txt/.md); JSON-экспорт Telegram
(`scripts/extract_telegram.py` — без `--from` покажет авторов; с `--from "Имя"`
соберёт корпус, отфильтровав форварды, медиа, ссылки). Дать и короткие реплики,
и пару длинных — поймать ритм. <5 образцов → честно предупредить: голос будет
приблизительным.

## Часть 3. Маппинг отчёт → шаблон

| Секция шаблона | Откуда (слой отчёта) |
|---|---|
| **Кто это** | интервью + «средняя длина образца» (Слой 2). Справка ДЛЯ МОДЕЛИ, в текст поста не выносить (иначе «меня зовут…» лезет в пост) |
| **Эталонные фрагменты** | ДОСЛОВНЫЕ образцы из корпуса (зачины, тезисы, концовки) — половина качества |
| **Off-brand / Табу** | контраст с `universal-anti-slop.md` + «чего в корпусе нет» + анти-правила интервью |
| **Словарный отпечаток** | Слой 1: «Подпись по служебным словам» (над/недо-употребление) + «Вводные» + «Стилистические обороты» дословно |
| **Ритм и композиция** | Слой 2 (burstiness/CV, тире) + Слой 3 (зачины-сигналы, % концовок-вопросов, доля одно-предложенческих абзацев) |

### Правила маппинга
- **Только настоящее.** Нет слова в отчёте — не пихать в подпись.
- **Стилистические обороты — дословно** («на самом деле», а не «на самом»).
  Раздел «Тематические обороты» в отчёте — это ТЕМЫ (имена/термины), НЕ голос.
- **Подпись — по отклонению.** Берём то, что автор над/недо-употребляет против нормы.
- **Тире-исключение.** Если отчёт говорит «автор сам активно сыплет тире» — смягчить
  пункт про тире в анти-слое: не баним, только защищаем от AI-накопления подряд.
- **Игра длиной.** Высокий CV → явно прописать «чередуй рубленые и длинные».
- **Концовки.** Если часто заканчивает вопросом / без точки — прописать явно.
- **Примеры — половина качества.** Всегда вставлять 3–5 настоящих фрагментов.

## Часть 4. Сборка и сохранение

1. Взять `voice-skill-template.md`, заменить все `{{...}}`.
2. Вместо `{{ANTI_SLOP}}` вставить секцию из `universal-anti-slop.md`.
3. Удалить пустые блоки (каналы/тональности, которых нет).
4. Создать `~/.claude/skills/voice-{{slug}}/SKILL.md`.
5. Проверить frontmatter: валидный `name` + `description` с триггер-фразами.
6. Сохранить `~/.claude/skills/voice-{{slug}}/references/voice-profile.json` (схема ниже).

### Схема voice-profile.json

```json
{
  "version": 1, "created": "2026-06-23", "updated": "2026-06-23", "language": "ru",
  "interview": {
    "name": "Имя автора", "slug": "voice-ivanov",
    "who": "род занятий, роль", "topics": ["тема 1", "тема 2"],
    "channels": [{"name": "Telegram-чат", "length": "до 300 символов", "purpose": "реплики"}],
    "style_phrase": "прямой, с иронией",
    "tonalities": ["нейтрально", "ироничнее"],
    "anti_rules": ["без хэштегов", "максимум 1 эмодзи"]
  },
  "corpus": ["образец 1 дословно", "образец 2 дословно"],
  "corpus_meta": {"samples": 12, "source": "telegram-export + вставка"},
  "measured": {"avg_len": 0, "cv": 0.0, "fillers": {}, "fw_over": [], "ngrams": [], "tire_heavy": false}
}
```

## Часть 5. Обновление существующего голоса

Триггер: «обнови голос», «добавь образцы», повторный запуск с тем же slug.

1. Прочитать `voice-profile.json`. Интервью **не повторять** — только уточнить изменения.
2. Новые образцы добавить к `corpus`; прогнать анализатор по объединённому корпусу.
3. Показать diff подписи (новые вводные/обороты ↔ выпавшие).
4. Пересобрать SKILL.md; обновить `corpus`, `corpus_meta`, `measured`, `updated`.
5. Нет профиля (скил собран руками) → честно сказать: нужны интервью + образцы заново;
   в конце сохранить профиль для будущих дозаливок.
