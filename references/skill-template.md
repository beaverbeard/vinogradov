# Шаблон сгенерированного скилла

Это «скелет» персонального voice-скилла. При генерации:
1. Заменить ВСЕ `{{...}}` плейсхолдеры реальными данными из интервью + отчёта `analyze_corpus.py`.
2. Удалить блоки, для которых нет данных (например, лишние каналы или тональности).
3. Встроить нужную языковую секцию из `references/universal-anti-slop.md` ВМЕСТО блока `{{ANTI_SLOP}}`.
4. Сохранить как `~/.claude/skills/{{skill-slug}}/SKILL.md`.

Frontmatter обязателен: `name` (kebab-case slug) и `description` (от третьего лица,
с триггер-словами, чтобы скилл вызывался автоматически).
